Quick Text Tutorial: How to Install rk-extension
Extract the ZIP File: Unzip your downloaded file. You will get a folder named radixkingdoms-main. Go inside it and locate the specific subfolder named rk-extension.

Open Extensions Page: Open Chrome, Brave, or Edge, type chrome://extensions (or edge://extensions for Edge) in the address bar, and press Enter.

Turn on Developer Mode: Enable the Developer mode toggle in the top-right corner of the page.

Load the Extension: Click the Load unpacked button (top-left) and select the rk-extension folder.
